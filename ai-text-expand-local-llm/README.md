# AI Text Expand Local LLM

Windows 11 utility for expanding selected text with a local LLM.

Workflow:

1. Highlight text in a browser webpage text field.
2. Right-click.
3. Choose a length option: **2 sentences**, **5 sentences**, or **paragraph**.
4. The selected text is replaced with a longer, clearer version generated by your local model.

This project uses:

- AutoHotkey v2 for the Windows right-click menu and copy/paste automation
- Python for the local LLM bridge
- Ollama for local LLM inference

## Setup

For most users, double-click:

```text
Install.cmd
```

Installation starts AI Text Expand automatically. You do not need to run another script after installation.

From this folder:

```powershell
.\scripts\install.ps1
```

The installer checks for Python, AutoHotkey v2, and Ollama. If `winget` is available, missing tools are installed automatically. It also starts Ollama and pulls the configured local model.

For Intel network PCs, the installer uses this proxy by default for downloads:

```text
http://proxy-dmz.intel.com:912
```

To use a different proxy:

```powershell
.\scripts\install.ps1 -Proxy "http://your-proxy:port"
```

To install without a proxy:

```powershell
.\scripts\install.ps1 -NoProxy
```

If the model download times out, the app install still completes but AI Text Expand does not start. Connect to a network that can reach `https://registry.ollama.ai`, then double-click `Install.exe` again. This is common on corporate networks that require a proxy, VPN, or firewall allowlist.

If your PC blocks `winget` installs, install Python 3.9+, AutoHotkey v2, and Ollama manually, then rerun:

```powershell
.\scripts\install.ps1 -SkipWingetInstall
```

To skip downloading the model during setup:

```powershell
.\scripts\install.ps1 -SkipModelPull
```

The default config is in `config.example.json`:

```json
{
  "LOCAL_LLM_MODEL": "llama3.1:8b-instruct-q4_K_M",
  "OLLAMA_BASE_URL": "http://127.0.0.1:11434",
  "timeout_seconds": 90
}
```

You can change the model name if you prefer another local model, such as `qwen2.5:7b`, `llama3.1:8b`, or another model installed in Ollama. Instruction-tuned models usually follow the length options more reliably.

## Run

The installer starts AI Text Expand automatically. Use this section only if you stopped the helper and want to start it again.

For most users, double-click:

```text
Run.cmd
```

Run:

```powershell
.\scripts\run.ps1
```

To ensure the helper starts automatically after sign-in:

```text
Enable_Startup.cmd
```

Or run:

```powershell
.\scripts\enable_startup.ps1
```

To quickly verify it is running (and auto-start it if it is not):

```powershell
.\scripts\health_check.ps1
```

Or double-click:

```text
ahk\ai_text_expand.ahk
```

Then:

1. Click inside a browser webpage text field.
2. Highlight text.
3. Right-click.
4. Select one of the AI length options:
  - **Expand with Local AI - 2 sentences**
  - **Expand with Local AI - 5 sentences**
  - **Expand with Local AI - paragraph**

If no text is selected, the normal right-click behavior is sent through.
The AI right-click menu is active only in supported browsers: Chrome, Edge, Firefox, Brave, Opera, and Vivaldi.
While the model is running, a small status tooltip shows the selected length and local LLM model name.
For the 2-sentence and 5-sentence options, the Python bridge validates the generated sentence count. If the model returns the wrong number of sentences, it automatically asks the model to rewrite before inserting the result.

## Package for Other PCs

Create a shareable zip from this folder:

```powershell
.\scripts\package.ps1
```

The package is created under `dist\`.

Send the zip file to another Windows PC. On that PC, the user should:

1. Extract the zip.
2. Double-click `Install.exe`.
3. Start using the right-click AI menu in a supported browser.

Optional startup setup: double-click `Enable_Startup.exe`.

If Windows blocks the unsigned executable, use the included `.cmd` fallback files instead: `Install.cmd`, `Run.cmd`, and `Enable_Startup.cmd`.

PowerShell alternative:

```powershell
.\scripts\install.ps1
```

## How It Works

The AutoHotkey script copies the highlighted text into a temporary file, calls the Python script, then pastes the generated output over the original selection.

The Python script sends a chat request to Ollama:

```text
POST http://127.0.0.1:11434/api/chat
```

The model is instructed to preserve meaning, tone, and language while making the sentence or paragraph longer and clearer.

## Notes

- Some protected apps may block simulated copy and paste.
- The right-click AI menu only appears in supported browser windows.
- To stop it, right-click the AutoHotkey tray icon and choose Exit.
- Ollama model download requires access to `https://registry.ollama.ai`. On Intel network PCs, the installer uses `http://proxy-dmz.intel.com:912` by default. If it still times out, verify proxy/VPN/firewall access and rerun `Install.exe`.
- For GitHub upload, this folder can be copied or initialized as its own repository.
